- Все начисления баллов идут только через `services/pointsLedger.award(...)` — прямое изменение
  `users.total_points` в обход этого метода запрещено.
- Admin-only handlers обязаны быть обёрнуты middleware проверки `admins` — не полагаться на UI
  (скрытую кнопку), которую всё равно можно обойти прямой командой.
- Никаких секретов в коде — только через `process.env`, с валидацией наличия при старте
  (`if (!process.env.BOT_TOKEN) throw ...`).
- Любой вызов Telegram API, который может упасть из-за действий пользователя (заблокировал бота,
  вышел из чата) — обёрнут в try/catch, ошибка логируется, процесс не падает.
- Рассылка (`services/broadcast.ts`) всегда с паузой между сообщениями и батчами — жёстко
  запрещено отправлять всем пользователям в цикле без задержки (риск бана бота Telegram).
- Тексты сообщений пользователю — импорт из `src/bot/texts/`, инлайн-строки с текстом для
  пользователя в handlers/services запрещены.
