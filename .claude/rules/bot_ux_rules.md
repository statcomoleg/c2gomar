globs: ["src/bot/texts/**/*.ts", "src/bot/keyboards/**/*.ts"]

- Формат карточек/сообщений — строго по TECH_SPEC.md (разделы 4.5, 4.7, 5.2), структура не
  меняется без обновления TECH_SPEC.md в первую очередь.
- Каждый текстовый шаблон — чистая функция `(params) => string`, без побочных эффектов и без
  обращений к БД/API внутри файлов `texts/`.
- Даты — только человекочитаемый формат (`dd.MM.yyyy HH:mm`), никогда сырой ISO пользователю.
- Эмодзи — умеренно, по смыслу (✅ ▫️ 🔁 🏆 💰 📝), не более одного-двух на сообщение.
- Тексты участнику — дружелюбные и краткие; тексты админу — компактные, деловые, без эмодзи-шума.
