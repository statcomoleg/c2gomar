# Skill: создание новой SQL-миграции Supabase

1. Определить следующий порядковый номер файла (`ls supabase/migrations/ | sort | tail -1`).
2. Создать файл `NNNN_short_description.sql`.
3. Каждая миграция — идемпотентна там, где возможно (`create table if not exists` для новых
   таблиц; для изменения существующих — обычный `alter table`, миграции применяются один раз и не
   переприменяются).
4. Обязательно: `enable row level security` в конце миграции, создающей новую таблицу.
5. Индексы — отдельным `create index` сразу после создания таблицы, с понятным именем
   (`{table}_{columns}_idx`).
6. Не редактировать уже применённые/закоммиченные миграции — только новый файл сверху.
7. После создания — прогнать `supabase db push` (или эквивалент) локально/на staging перед тем,
   как считать миграцию готовой.
